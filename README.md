# Veda Task 30 – Regional Growth Analysis

## Objective
Analyze and compare regional sales growth over time using SQL and Excel.

## Tools Used
- MySQL
- Microsoft Excel
- Superstore Dataset

## Analysis
The analysis calculates year-over-year sales growth for four regions:
- Central
- East
- South
- West

The analysis covers 2014–2017 sales data and calculates growth for 2015–2017.

## Key Insights
1. West showed the strongest sustained growth, with an average growth of 20.67%.
2. South experienced the largest decline in 2015 at -31.28%.
3. Central showed the highest volatility, ranging from -0.93% to 43.31%.
4. East maintained positive growth throughout all three periods.
5. 2016 was a broad-based growth year, with all four regions recording positive growth.

## Deliverables
- Excel growth analysis
- Regional growth chart
- SQL analysis queries
- Key business insights
